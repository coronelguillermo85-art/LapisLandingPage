## 📌 Descripción del proyecto

Landing page institucional desarrollada para **LAPIS** (Laboratorio de Prácticas e Investigaciones Sociales), con el objetivo de promocionar el programa formativo **"Del Deseo al Proyecto"**.

El sitio presenta de manera clara y persuasiva los componentes del programa, su enfoque metodológico, modalidades de participación y testimonios de quienes ya pasaron por la experiencia. Está diseñado para convertir visitantes en potenciales participantes, reflejando la identidad visual y los valores de la organización: **equidad, transformación social y acompañamiento estratégico**.

Este proyecto forma parte de mi portafolio profesional como desarrollador front-end, demostrando mi capacidad para traducir identidades institucionales en experiencias digitales funcionales y estéticas.

<br>

## 🎯 Características principales

- ✅ **Diseño 100% responsive** — adaptado a dispositivos móviles, tablets y desktop.
- ✅ **Estructura semántica** — HTML5 accesible y bien organizado.
- ✅ **Estilizado con CSS puro** — sin frameworks externos, con variables CSS para mantener consistencia.
- ✅ **Iconografía vectorial** — FontAwesome para una comunicación visual efectiva.
- ✅ **Tipografía elegante** — combinación de *Inter* y *Playfair Display* desde Google Fonts.
- ✅ **Enlaces funcionales** — redes sociales, correo electrónico y sitio web de LAPIS completamente integrados.
- ✅ **Llamados a la acción (CTAs) diferenciados**:
  - Botón **"Inscribirme"** → abre un **formulario modal integrado** (envío vía FormSubmit).
  - Botón **"Consultar"** → abre el cliente de correo con destino `lapis.ac@gmail.com`.
- ✅ **Formulario de inscripción sin backend** — usa FormSubmit para reenviar los datos al correo de LAPIS.

## 🛠️ Tecnologías utilizadas

- **HTML5** — Estructura y maquetado.
- **CSS3** — Estilos, animaciones y diseño responsive (sin frameworks).
- **FontAwesome** — Librería de iconos vectoriales.
- **Google Fonts** — Tipografías *Inter* y *Playfair Display*.
- **FormSubmit** — Servicio gratuito para enviar correos desde el formulario sin necesidad de backend.
